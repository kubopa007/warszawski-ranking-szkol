# Warszawski Ranking Szkół

Portal z rankingiem, katalogiem i (etap 2) dopasowaniem szkół w Warszawie. Ranking z jawną metodologią, liczony wyłącznie z danych oficjalnych. Projekt open source, we wczesnej fazie — **brak jeszcze funkcjonalności**.

**Stack:** Next.js (App Router) + Payload CMS 3 · PostgreSQL (Neon) · TypeScript · pnpm monorepo.

```bash
pnpm install
pnpm check
```
