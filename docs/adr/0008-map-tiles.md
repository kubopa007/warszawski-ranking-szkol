# 0008. Kafelki mapy: Protomaps (R2) lub MapTiler

Status: Proposed (termin: 2026-11-15) | Data: 2026-10-16

## Kontekst

Biznesplan: Leaflet + publiczne serwery OSM, których polityka nie pozwala na ruch produkcyjny.

## Decyzja

Leaflet + react-leaflet; kafelki Protomaps (PMTiles na R2) albo MapTiler Free. Wybór jednego — do decyzji.

## Konsekwencje

Development może korzystać z publicznych kafelków OSM wyłącznie lokalnie i z atrybucją.
